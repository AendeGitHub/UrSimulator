<h1 align="center">UrSim</h1>

<p align="center">Симулятор FIRST Tech Challenge сезона 2026–2027 <b>BIOBUZZ</b> от команды <b>URAN92</b></p>

<p align="center"><a href="../../releases/latest"><b>⬇ Скачать последнюю версию</b></a> · <a href="https://ursim.onrender.com">Играть в браузере</a></p>

![Главное меню](docs/menu.jpg)

Водишь робота **URAN V1** (мекан-шасси, автоматическая турель, интейк и шутер) по полю BIOBUZZ: собираешь POLLEN и NECTAR, переворачиваешь улей, играешь «Матч 2:30» с подсчётом очков и судьёй по мануалу или тренируешься без таймера. **Онлайн 2 на 2** — до 4 игроков в комнате по коду из 4 букв. Есть таблица рекордов для каждого робота.

## Скачать

Все версии — на странице [Releases](../../releases). Выбери архив под свою систему:

| Система | Файл |
|---|---|
| Windows 10 / 11 (64-бит) | `UrSim_<версия>_Windows.zip` |
| macOS 12+ (Intel и Apple Silicon) | `UrSim_<версия>_Mac.zip` |
| Linux (64-бит) | `UrSim_<версия>_Linux.zip` |

Без установки можно играть в браузере: **https://ursim.onrender.com** (Chrome, Edge, Firefox, Safari).

## Как запустить

**Windows.** Распакуй архив (правый клик → «Извлечь всё») и запусти `UrSim.exe`. Если появится «Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае»: у игры нет платной подписи Microsoft.

**macOS.** Распакуй архив и перетащи `UrSim` в «Программы». При первом запуске нажми на `UrSim` правой кнопкой → «Открыть» → «Открыть» (у игры нет подписи Apple). Если macOS пишет, что приложение «повреждено» или его «не удаётся проверить», открой Терминал и выполни:

```bash
xattr -cr /Applications/UrSim.app
```

**Linux.** Распакуй архив и запусти исполняемый файл `ursim` из распакованной папки.

`F11` — полный экран.

## Управление

Геймпады PS4, PS5 и Logitech F310 (как на FTC Driver Station) или клавиатура. Любую кнопку и клавишу можно переназначить в **Настройки → Управление**.

| Действие | PS4 / PS5 | Logitech F310 | Клавиатура |
|---|---|---|---|
| Езда и стрейф | левый стик | левый стик | W A S D |
| Поворот | правый стик | правый стик | Q / E |
| Интейк (держать) | L1 | LB | F |
| Выкинуть мячи (держать) | ↓ | ↓ | K |
| Шутер включить / выключить | L2 / R2 | LT / RT | Z / V |
| Трансфер в шутер (держать) | R1 | RB | Space |
| Пауза | PS | Logitech | Esc |

## Если тормозит

**Настройки → Графика**: качество «Низкое», тени выключить. «Авто» само снижает качество, если FPS падает ниже 50. Нужна видеокарта с поддержкой WebGL 2 (почти любая с 2015 года); для онлайна нужен интернет.

## English

UrSim is a fan-made simulator of the FIRST Tech Challenge 2026–2027 game **BIOBUZZ** by FTC team **URAN92**: drive the URAN V1 robot, score POLLEN and NECTAR, tip the HIVE, play 2:30 matches with automatic scoring and refereeing, or play **online 2 vs 2** with friends. Download the zip for your OS from [Releases](../../releases): on Windows run `UrSim.exe`, on macOS right-click → Open on first launch, on Linux run `ursim`. Or play in the browser at https://ursim.onrender.com.
